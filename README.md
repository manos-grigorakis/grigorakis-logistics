## Overview

This project is a modern and responsive landing page for a medium-sized logistics company. The main objective of the website is to establish an online presence and attract potential customers through a simple and professional interface.

## Core Features

- Responsive Design
- Clean & Modern UI
- Contact Form with Automated Emails via Resend

## Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

## Setup

1. Clone the repo

   ```bash
   git clone https://github.com/manos-grigorakis/grigorakis-logistics.git
   cd grigorakis-logistics/frontend
   ```

2. (Optional) Configure environment variables

   ```bash
   cp .env.example .env.local
   ```

3. Install dependencies

   ```bash
    npm install
   ```

4. Run development server
   ```bash
    npm run dev
   ```
